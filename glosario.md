# Glosario — Préstamos de Biblioteca

| Término (el idioma del negocio) | Identificador en `dominio/` | Significado |
|---|---|---|
| Socio | ¿? | Persona registrada que recibe ejemplares en préstamo. |
| Ejemplar | ¿? | Copia física de un libro que puede prestarse. |
| Préstamo | ¿? | Relación de un ejemplar con un socio desde una fecha. |
| Plazo | ¿? | Cantidad de días permitida para conservar el ejemplar. |
| Vencimiento | ¿? | Fecha límite en que debe devolverse el ejemplar. |
| Devolución | ¿? | Registro de que el ejemplar fue devuelto. |
| Atraso | ¿? | Días transcurridos después del vencimiento. |
| Multa | ¿? | Importe generado por una devolución atrasada. |
| Multa por día | ¿? | Importe aplicado por cada día de atraso. |
| Límite de préstamos | ¿? | Máximo de préstamos activos permitidos a un socio. |
| Cuenta de préstamos | ¿? | Historial de préstamos activos y devueltos de un socio. |
